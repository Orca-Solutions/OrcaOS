# Component SDK

Libraries that Diamond Dog components will link against. Nothing is here yet:
the SDK waits for the real runtime, whose design the first experiment's
results decide. Products building on Diamond Dog today use the
[provisional contract](../interfaces/diamond-dog/provisional-contract.md) and
the [fake Diamond Dog](../fake/README.md).
